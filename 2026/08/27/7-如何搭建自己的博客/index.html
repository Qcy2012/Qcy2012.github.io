如何搭建自己的博客

前言

基本条件

你需要拥有：

  • 健全的身体
  • 一台能正常使用的电脑
  • 一点点耐心

没有的请自觉离开。
如果不愿意花时间，也请离开。

准备工作

  1. 一个Github账号 官网地址,注册账户网址,如果无法访问请耐心等待,或考虑使用WattToolkit
  2. 一个digitalplat账号 官网地址 ,点击右上角注册,里面的信息可以随便填
  3. nodejs 官网地址 ,点击下面的“Windows 安装程序(.msi)”按钮下载
  4. git 官网地址 ,会直接开始下载,下载速度较慢,请耐心等待。

更改nodejs环境变量

注意：这一步非常重要！

  1. 打开你安装nodejs的文件夹根目录，新建”node_cache”和”node_global”文件夹
  2. 搜索“查看高级系统设置”并打开，选择”环境变量”，选择用户环境变量中的PATH，检查有没有”%你安装nodejs的根目录%\node_modules”变量，如没有就添加。
  3. 在系统环境变量中添加名称为”NODE_PATH”的环境变量，值为”%你安装nodejs的根目录%\node_modules”。
  4. 将第一步新建的两个文件夹”node_cache”和”node_global”的users权限设置为”完全控制”。
