1-Markdown学习笔记

发表于 2026-07-30 更新于 2026-07-31 分类于 学习

Markdown学习笔记

因为Hexo要用Markdown写文章，所以就有了这篇学习笔记

标题类

格式：

“#”表示一级标题
“##”表示二级标题
“###”表示三级标题
“####”表示四级标题
“#####”表示五级标题
“######”表示六级标题

粗体、斜体、斜粗体类

格式：

两边各两个星号表示粗体：粗体
两边各一个星号表示斜体：斜体
两边各三个星号表示斜粗体：斜粗体

列表类

格式：

普通列表

无序列表：+/-/*
有序列表（数字可以不连续）：1.
2.
3.
列表可以嵌套，只需要在子列表的标记符号前面添加两个或四个空格即可，保持缩进长度尽量一致。

任务列表

任务列表：- [ ]
- [x]

引用类

格式：

“> “（紧跟一个空格）表示引用
多级引用只需重复基础引用的符号即可（要加空格！）

代码类

格式：

这是一段代码

“```”（两边都要）表示一个代码块

链接类

格式：

普通链接

“[链接名称]”(链接URL “可选标题”)”

参考链接

“[参考链接]: URL “可选标题””

图片类

格式：

“![替代文字]”(URL “可选标题”)”

比如：

相对路径：”![favicon]”(./images/favicon.ico)”
绝对路径：”![screenshot]”(C:\Users\Administrator\Pictures\screenshot.jpg)”

表格类

格式：

“|表头|表头|
|—-|—-|
|单元格|单元格|
|单元格|单元格|”

对齐方式：

“:—“表示左对齐
“—:”表示右对齐
“:—:”表示居中对齐

分割线类

格式：

“***”/“—“/“___”都可以
符号中间可以有空格，也可以使用三个以上的符号

数学公式类

格式：

  1. 命令：以反斜杠 “" 开头，如 \alpha、\sum
  2. 参数：用花括号 “{}” 包围，如 \frac{a}{b}
  3. 下标：使用 “_” ，如 x_1
  4. 上标：使用 “^” ，如 x^2
  5. 分组：用花括号将多个字符组合，如 x_{i+1}

行内公式与块级公式

用单个符号 “$” 包裹，如函数$f(x)=x^2+2x+1$

图表类

格式：

例如： 

graph TD
    A[开始] --> B{条件判断}
    B -->|Yes| C[执行操作A]
    B -->|No| D[执行操作B]
    C --> E[结束]
    D --> E

其他注意事项

  1. 换行要用尾随至少两个空格+一个换行符，或两个换行符
  2. 标记符号（如+/-/*）后面要跟一个空格
